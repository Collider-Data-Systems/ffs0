# Ontology v3.9 — T=168 baseline audit

> T=168 (April 18, 2026). Side-step from T=187 spec-enrichment conversation.
> Origin: sam's push to "do it proper, not just a bump version but a full version audit as baseline at t168."

## Why a v3.9 audit now

Round 1 of T=168 landed §M11..§M17 on top of v3.8. The work surfaced **collisions and gaps** that the ontology must address before it can carry the §M18..§M20 generalization cleanly (session as workspace anchor, agent as occupant, CLI-as-tool-making-tools).

Sam's framing for the audit:

> "consider the carpet as conceptual free category, superset. consider classification schemas DSLs, purpose, session, program, WFs, functorial semantics. [...] the pattern must be expressive enough to map natural language and intent meaning purpose whatever to classification schemas benchmarks, industry terms like skill harness workflow etc. s1 should provide semantic embedding for new grammar and types from the s4."

S1 = Source of Truth grammar. v3.9 is its baseline moment.

### E. Categorical / functorial gaps

- **CI-1 (Church-Rosser):** declared as invariant, no testable constraint in WFs. v3.9 adds an `audit_note` on each WF flagging whether it is CR-safe (all current 19 WFs are, given log-is-truth + fold-is-deterministic). Post-v3.9 can add per-WF contract declarations.
- **CI-4 (log replay determinism):** no fold specification. v3.9 adds `fold_contract` sibling to `invariants`: declare fold signature + non-determinism exclusions. Brief — full formalization is a T=187 sub-program's job.
- **WF composition:** no declared `compose` operator on WF pairs. Not fixed in v3.9; noted in `audit_note` as future work.
- **Morphism equations:** the ontology today is effectively **a free category** on its generators — no equations imposed beyond port compatibility and permission inheritance (CI-5). v3.9 states this explicitly in a new top-level `free_category_note`.

### F. S1 as semantic embedding superset (the central gap)

Currently:
- `system_instruction` (S4 overlay) is read-only toward S1
- `governance_proposal` (S0–S2) exists but has no mechanism to promote evidence → new type
- No path for observed patterns to become first-class S1 grammar

**The pattern Sam is reaching for:** an adjoint between free-form intent (S4) and formal grammar (S1). v3.9 introduces the **`grammar_fragment` type (D3)** and a **new workflow category WF20 `grammar_promotion`** to carry the promotion path:

```
S4 system_instruction / observation
   │
   │  (extract candidate type/port/WF)
   ▼
S2/S0 governance_proposal
   │
   │  WF20 grammar_promotion — authorizes + accepts
   ▼
S1 grammar_fragment (candidate)
   │
   │  WF20 on merge into ontology baseline
   ▼
S1 canonical type / WF / port
```

**Adjoint reading.** Left adjoint: `Promote : S4-observation → S1-generator` (grows S1). Right adjoint: `Express : S1-grammar → S4-expressible-form` (grounds S1 into instruction language). Unit/counit establish round-trip coherence: an S1 type should be expressible in natural S4 language; a S4 pattern that surfaces repeatedly should promote to an S1 generator.

WF20 is declared in v3.9 with minimal mutate_scope and src/tgt_types; the full promotion algorithm (how evidence aggregates into a proposal, how acceptance is signed) is specified in a new T=187 sub-program proposal (see §M21 in the v3.9 spec addendum — held for the next round).
