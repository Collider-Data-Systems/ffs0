## Problem

No CI. Tests and builds are manual. Contributors can't verify their changes pass before PR.

## Solution

Create `.github/workflows/ci.yml` with:

### Jobs

1. **test** — `go test ./platform/kernel/...` on push/PR
   - Go versions: 1.22, 1.23
   - OS: ubuntu-latest (primary), windows-latest (secondary)
   - Includes `go vet ./...`

2. **build** — `go build ./platform/kernel/cmd/moos`
   - Matrix: linux/amd64, darwin/amd64, darwin/arm64, windows/amd64
   - Upload artifacts for release

### Triggers

- Push to `main`, `chore/*`, `feat/*`, `fix/*`
- Pull requests to `main`

### Notes

- Zero external deps means no dependency caching needed (stdlib only)
- Tests use `../../../../` relative paths to repo root — ensure working directory is correct
- No golangci-lint initially — `go vet` is sufficient for v0.1.0

## Acceptance Criteria

- [ ] Push to branch triggers CI
- [ ] All 8 test packages pass on ubuntu
- [ ] Build succeeds for linux/darwin/windows
- [ ] PR shows green check
