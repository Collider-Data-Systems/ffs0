## Problem

The scope selector (Task 022) filters by OWNS subgraph only. v0.2 needs parametric filtering — by kind, stratum, category, port, or neighborhood — composable with scope. This is the backend for the new Data Lens Explorer.

## Solution

New `internal/lens/` package. Pure function: takes a `GraphState` + `LensSpec`, returns a filtered `GraphState`. No IO, no side effects — same pattern as `internal/fold/`.

// Rule is a single predicate over the graph. Fields are conjunctive —
// if both Kind and Stratum are set, both must match.
type Rule struct {
	Kind         []cat.TypeID  `json:"kind,omitempty"`
	Stratum      []cat.Stratum `json:"stratum,omitempty"`
	Category     []string      `json:"category,omitempty"`
	Port         string        `json:"port,omitempty"`
	Neighborhood *Neighborhood `json:"neighborhood,omitempty"`
}

type Neighborhood struct {
	Origin cat.URN `json:"origin"`

}

### Apply algorithm

1. For each Rule, compute the set of URNs matching that rule
2. Within a Rule: fields are conjunctive (AND). Start with all nodes, intersect with each non-empty field filter
3. Between Rules: use `Mode` — `"intersect"` means AND across rules, `"union"` means OR
4. Build result: include matched nodes + wires where BOTH endpoints are in the matched set

### Neighborhood BFS

- depth=0: origin node only
- depth=N: BFS N hops from origin, following wires in both directions
- Max depth cap: 10 (prevent full-graph traversal)
- Unknown origin URN: return empty GraphState

### ParseQueryParams examples

```
?kind=provider,agnostic_model    → Rule{Kind: ["provider", "agnostic_model"]}
?stratum=S2,S3                   → Rule{Stratum: ["S2", "S3"]}
?category=compute                → Rule{Category: ["compute"]}
?port=CAN_ROUTE                  → Rule{Port: "CAN_ROUTE"}
?neighborhood=urn:moos:...&depth=2 → Rule{Neighborhood: {Origin: "urn:moos:...", Depth: 2}}
```

Multiple params on GET = single Rule with conjunctive fields.

### File: `platform/kernel/internal/lens/lens_test.go`

Table-driven tests:

| Test case | Input | Expected |
|-----------|-------|----------|
| Filter by single kind | `kind=provider` | Only provider nodes + their internal wires |
| Filter by multiple strata | `stratum=S2,S3` | Nodes at S2 or S3 |
| Filter by category | `category=compute` | agnostic_model, system_tool, program_invoke |
| Filter by port | `port=CAN_ROUTE` | Nodes with CAN_ROUTE wires |
| Neighborhood depth 1 | origin + depth=1 | Origin + direct neighbors |
| Neighborhood depth 0 | origin + depth=0 | Origin only |
| Intersect two rules | kind=provider AND stratum=S2 | Providers at S2 only |
| Union two rules | kind=provider OR kind=user | Both sets |
| Empty rules | no rules | Full state (identity) |
| Wire inclusion | filter nodes | Only wires between included nodes |
| Unknown neighborhood | bad URN | Empty GraphState |
