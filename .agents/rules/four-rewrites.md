# The Four Rewrites Rule

Four rewrites only: **ADD · LINK · MUTATE · UNLINK**.

- **Log is truth. State is derived.**
- Nodes don't call things; relations don't carry messages; side effects occur only at actuator leaves via channels.
- Authoritative vocabulary: `kb/superset/ontology.json`.
- Nomenclature — use: node · relation · rewrite · property · operad · port · rewrite_category WF01..WF21 · `_urn`/`_urns`.
- Never: edge · wire · field · mutation · schema · association · binding · `_ref` · (for interaction nodes) transition/event/message.
